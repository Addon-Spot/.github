## About AddonSpot

AddonSpot is a team of browser extension developers. We build cross-browser extensions and lightweight web tools for Chrome, Firefox, and Edge. Every project starts with a real problem, something slow, repetitive, or confusing, and ends with a simple tool that fixes it.

## How we build

- **Problem first:** we start with a real browsing or workflow pain point, not a feature list
- **Simple by design:** one job, done well, with no bloat
- **Cross-browser:** built with the WebExtensions API so it works across major browsers
- **Privacy-minded:** we ask for only the permissions a tool actually needs
- **Open to feedback:** your bug reports and ideas shape what we ship next
